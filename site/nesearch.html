01What it does

From “I remember that game” to playing it.

Six catalogs, one list

GitHub retrobrews, Homebrew Hub, PDRoms, Internet Archive, plus TuxNES mapper and Fogleman screenshot metadata.

CLI and local UI

The same catalog, download and library services behind a terminal and a loopback-only Web UI.

Downloads that verify

Resume, retry, atomic rename, iNES parsing and SHA-256 checks before a ROM joins the library.

A real local library

Grid and list views, search, verify, and delete — backed by a plain JSON index.

Bundled emulators

GEM6502 and NEMU/6502EMU ship in the macOS package; the Play button resolves them without configuration.

Bring your own catalog

Point it at a custom JSON source, test the connection, and merge it into the same search.

04Quick start

Unzip. Run. Search.

Start the app

./run-ui.command

Or stay in the terminal

./nesearch update
./nesearch search falling
./nesearch download falling -o ~/Downloads
05Requirements

What you need to know.

  • macOS 12+ on Apple SiliconThe current package is arm64 only. Intel and Windows builds are not published yet.
  • Unsigned binariesNo Developer ID or notarization yet; clear the quarantine attribute once after unzipping.
  • Some sources are flakyInternet Archive can be unreachable; PDRoms exposes only the latest 10 entries.
  • Local onlyThe UI binds to 127.0.0.1 with a one-time token. Nothing is uploaded.

nesearch is part of the Open6502 project. NEMU is distributed under Mulan PSL v2 and SDL2 under zlib; see the bundle's LICENSES directory.
