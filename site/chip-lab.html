控制火候

芯片不神秘：它只是把“开关”做得非常非常小。小到一根头发丝里，能放下成千上万个开关。
小问题：如果把这些东西里的芯片都拿走，哪一个会最先“罢工”？

02 · 芯片是什么03 / 19
INSIDE THE CHIP

一座“指甲盖上的城市”

把芯片放大，你会看到一座规划得整整齐齐的城市：有指挥中心、仓库、画家、音乐家，还有无数条道路。

01

晶体管 = 小开关

现代芯片里有几十亿个开关；每个只有“开”和“关”两种状态。开就是 1，关就是 0。

02

导线 = 道路

把 0 和 1 的信号，送到需要它的地方。路修得越好，信号跑得越快。

03

模块 = 街区

CPU、内存、图形、声音，各有各的工作，又通过总线互相说话。

开 = 1，关 = 0。两个数字，就能写出游戏、音乐和整座城市。
芯片不是“画”出来的，而是用一层层材料“做”出来的。下一站：从沙子开始。
晶体管不用讲得太深，先把它当成“电控小开关”。可以让孩子用手指比划：开是 1，关是 0。很多开关排在一起，就能表示数字、文字、图片和声音。补充一个对比：现代处理器有几十亿个晶体管，而 6502 只有几千个，但已经足够跑游戏。

FROM SAND TO SILICON

从一粒沙，到一片“硅圆饼”

芯片的“地基”是硅。硅藏在沙子里，但要先提纯、拉成硅锭、切成薄片，才能变成晶圆。

05

晶圆

像一张大披萨

硅是地壳里第二多的元素。沙子、石头里都有它，但要做芯片，必须提纯到非常非常干净。

一片晶圆，能切出几百到几千颗芯片。每颗芯片只占晶圆上一个小小的方格。

为什么要在无尘室？一粒灰尘落在晶圆上，就可能毁掉一颗芯片。

小问题：如果一颗灰尘就能毁掉芯片，工程师进车间前要穿什么？
沙子的主要成分是二氧化硅，硅是地壳中第二多的元素。电子级硅的纯度可以做到 99.9999999%（9 个 9）。晶圆像一张大披萨，每一小块就是一颗芯片。可以让孩子猜猜：为什么要穿无尘服？

05 · 香山是谁06 / 19
XIANGSHAN · OPEN RISC-V

香山，不是一座山

它是一颗开源 RISC-V 处理器的名字。一群工程师、学生和公司把设计、验证和工具公开，让全世界一起参与。

THE NAME

“香山”是一颗开源处理器，不是旅游景点。

它的前身是果壳（NutShell）；“一生一芯”让更多学生从零设计 RISC-V 芯片。香山把这件事推到了高性能、可迭代、面向流片的规模。

01

开源

设计、验证、工具公开，任何人都能检查、学习、贡献。

02

RISC-V

一种开放的指令集，像芯片世界的“普通话”。

03

敏捷

参考模型、锁步 DiffTest、CI 门禁，让改动分钟级得到反馈。

04

一起造

研究所、公司、学生和社区一起做，不靠一个人闭门造车。

果壳 NutShell→香山 XiangShan→下一颗芯片？
小问题：如果芯片设计也像开源软件一样公开，会发生什么？
香山不是一座山，是一颗开源 RISC-V 处理器。它的前身是果壳（NutShell），“一生一芯”让更多学生从零设计 RISC-V 芯片。重点不是让孩子记住机构名字，而是理解：芯片也可以像开源软件一样，一群人一起做、一起检查。
06 · 香山模式07 / 19
THE XIANGSHAN WAY · 01

三个环，越转越快

香山把芯片开发拆成三个时间尺度的环：内环要快，中环要稳，外环要真。先跑短，再跑大。

01分钟
INNER LOOP

内环 · 先跑短

参考模型 + 锁步 DiffTest + 确定性回放。

改一行 RTL，一条命令，2 分钟内看到 PASS 或第一个差异。
像每天做一道练习题，做完立刻对答案。
02每次提交
MIDDLE LOOP

中环 · 每次提交

CI 回归、golden 哈希、失败 trace、required check。

PR 不绿不能合；同种子跑两遍，结果必须一致。
像每周小考，错题必须订正。
03每次迭代
OUTER LOOP

外环 · 每次迭代

综合、FPGA、开放 PDK 后端、PPA 报告。

上板稳定，流片门禁逐项有证据。
像每学期做一次大项目。
香山用约半年跑一次外环；Open6502 可以压缩到一周。练的是环与环之间的门禁纪律，不是环的尺寸。
小问题：如果内环很慢，每次改一行代码都要等一天，会发生什么？
三个环不是三个部门，而是三种反馈速度。内环最快，中环每次提交，外环每次迭代。先跑短，再跑大；如果内环很慢，工程师就不敢改、也不敢验证，整个流程会退回手工调试。可以让孩子用“每天练习 / 每周小考 / 每学期大项目”来记。
07 · 香山模式08 / 19
THE XIANGSHAN WAY · 02

七道门：每一步都要交证据

香山式流程（Open6502 提炼版）用 S0–S6 七道门检查：上一道没过，不许进下一道。

S0

契约冻结

做什么、接口、地址、时钟，先写清楚；接口不能还是 TBD。

S1

参考模型 + 镜像

先写一个独立“标准答案”；同一镜像构建两次，字节相同。

S2

单元 + 总线

小块先过关；总线一次只做一件事，地址译码不能撞车。

S3

锁步 DiffTest

和参考模型逐条对答案；第一个差异立刻停，打印现场。

S4

CI + 检查点

每次提交自动考试；能回到任意一步重放，结果一致。

S5

FPGA

上真板子跑，连续稳定至少 1 小时，不是“能综合”就算过。

S6

ASIC / PDK

时序、DRC/LVS、DFT、封装都签核，才敢说流片就绪。

WHY GATES?

为什么要七道门？

  • 不跳步：上一道没过，不许进下一道。
  • 可复现：每条命令都能再跑一遍。
  • 有证据：命令 + 产物 + 已知限制。

“没有命令的目标，等于不存在。”

小问题：如果跳过 S3 直接流片，可能会发生什么？
S0–S6 是 Open6502 对香山式流程的提炼表述，不是香山官方唯一编号；重点是“每一步都要有证据”。可以把它想成游戏关卡：上一关没过，不能进下一关。每道门都必须能回答：用什么命令跑？产出什么？还有什么已知限制？
08 · 香山模式09 / 19
THE XIANGSHAN WAY · 03

香山为什么能“快”？四件法宝

不是加班，而是把重复的事情交给机器，把判断留给工程师。

01

参考模型

独立写一个“标准答案”，不和 RTL 共享实现。它不被综合，只负责对答案。

02

锁步 DiffTest

同一镜像，两条队伍同时走；每一步对答案，第一个差异立刻停。

03

CI + 检查点

每次提交自动跑 lint / sim / difftest / golden；PR 不绿不能合；能回到任意一步重放。

04

生成化 + 开源

香山用 Chisel 生成 Verilog；设计、测试、工具公开，大家一起检查。

改一行 RTL → 一条命令 → 分钟级看到 PASS 或第一个差异。 一杯水还没喝完，答案就出来了。

THE INNER LOOP
小问题：这四件法宝里，哪一件最像“考试”？哪一件最像“标准答案”？
香山八件套里，最适合小学生先记住这四件：参考模型、锁步 DiffTest、CI/检查点、生成化/开源协作。参考模型是标准答案，DiffTest 是逐题对答案，CI 是自动考试，Chisel 是用更高级的积木描述电路。不要让孩子觉得“快”是靠加班，而是靠自动化和纪律。

10 · 写 RTL11 / 19
WRITE THE HARDWARE · S2

写 RTL：用“硬件语言”写下电路

软件像写步骤，硬件像画电路。香山用 Chisel 生成 Verilog，Open6502 手写 SystemVerilog——工具不同，门禁相同。

// 每个时钟上升沿，如果写使能为 1
always @(posedge clk) begin
  if (we)
    mem[addr] <= din;
end
01

不是“指令表”，是“电路说明书”。它描述的是电线怎么连、寄存器什么时候更新。

02

软件一步一步，硬件同时工作。很多电路会在同一个时钟节拍一起动。

03

写错一行，可能整颗芯片都受影响。所以后面才需要仿真和验证。

时钟就像节拍器。“时钟上升沿”就是大家一起迈出下一步的那一刻。芯片里的很多动作，都跟着这个节拍走。
小问题：如果软件是“按顺序做”，硬件为什么可以“同时做”？
不需要让孩子学会 Verilog，只要知道它和 Scratch 不一样：Scratch 是一步一步执行，硬件语言是在描述“电路长什么样、什么时候一起动”。时钟就是节拍器，上升沿就是大家一起迈步的那一刻。
11 · 仿真12 / 19
SIMULATE FIRST · 内环

仿真：先在电脑里“虚拟制造”

这是香山模式的内环日常：先在电脑里跑起来，改一行、再跑一遍，分钟级看到结果。仿真不是“跑一次看看”，而是每天都要做的练习题。

01

测试激励

给芯片输入一组“题目”：复位、读内存、按手柄。

02

DUT · 被测设计

把 RTL 放进仿真器，让它按节拍一步一步跑。

03

结果与波形

看输出对不对，再看每一根信号什么时候变。

像飞机模拟器

先在地面练熟，再真正起飞。

不用真的做出一颗芯片，就能试几百万次。发现 bug 时，改代码、重跑，成本很低。

但是……

仿真通过 ≠ 芯片一定正确。

测试写漏了，bug 就可能溜过去。所以还需要下一关：验证。

仿真不是“跑一次看看”。工程师会写很多测试，覆盖正常情况、边界情况和“故意捣乱”的情况。
小问题：为什么不在电脑里多跑几次，而是要做真芯片？因为真芯片还要考虑速度、功耗、发热和制造。
仿真就像飞机模拟器：先在地面练熟，不用真的起飞。给芯片输入测试激励，让 RTL 跑起来，再看输出和波形。强调“仿真通过不等于一定正确”，为下一页锁步 DiffTest 做铺垫。

锁步 DiffTest：像侦探一样“找不同”

先写一个能玩的模拟器

再用 SystemVerilog 写一遍

它描述真正要变成芯片的电路。每一帧画面、每一个状态，都要和参考模型对上。

13 · 验证14 / 19
FORMAL VERIFICATION · 数学保证

形式化验证：给芯片写一张“数学保证”

仿真像“抽考”：只检查做过的题；形式化验证像“证明”：对所有输入都保证答案正确。Open6502 用 Lean 4 给 CPU 写了一部分这样的保证。

SPEC · 说明书

它“应该”怎么工作

把加减法、进位、地址规则写成数学

比如：A 加 M 再加进位，结果是多少、进位和溢出怎么置位。这是“标准答案”。

IMPL · 电路

它“实际”怎么工作

把 RTL 的每个周期、每个寄存器写进模型

同一个 CPU，用 Lean 一行行写出来；再证明：跑完一条指令，两边状态永远一样。

151条官方指令的译码与 RTL 对得上
19条指令证明“跑 n 周期 = 说明书”
2¹⁶组操作数，加减与十进制全证明
和 DiffTest 的区别：DiffTest 是“跑起来找不同”，只能覆盖跑过的程序；形式化是“对所有情况做证明”，但只覆盖建模到的那部分。两者一起用，才既广又深。
诚实边界：目前只证了 19 / 151 条指令；中断、复位和精确周期还没证。数学保证也要一步一步来。
小知识：证明用 Lean 4 写；lake build 跑一遍约 15 秒，没有一句 “sorry”（先跳过、以后补）= 没有偷偷留坑。
形式化验证是芯片研发里的“数学保证”。仿真和 DiffTest 像抽考：跑很多程序，发现不同就报错，但没跑到的角落可能漏掉。形式化验证先写“说明书”（规格），再写“实现”（RTL 的逐周期模型），然后用证明器证明两者对所有输入都一致。Open6502 目前的成果：151 条指令的译码与 RTL 完全对得上；加减法和十进制（BCD）对所有 8 位操作数都证明；19 条指令证明“跑 n 个周期后状态正好等于说明书”；15 个小程序由证明器直接执行；4 个程序和真实 RTL 协同仿真一致。边界也要讲清楚：只覆盖 19 条指令，中断/复位/周期时序还没证。可以问孩子：抽考和“保证所有题都会做”，哪个更难？
14 · 走向工厂15 / 19
THE XIANGSHAN WAY · 外环

外环：从 FPGA 到流片

内环保证“做对”，外环保证“做得出来”。综合、布局布线、FPGA、PDK、签核，一步都不能少。

01

RTL

人写的电路说明书：功能、时序、接口。

.sv / .v
02

综合

翻译成门电路：与门、或门、触发器。

netlist
03

布局布线

给几百万个零件安排座位，再把线连好。

layout
04

GDS / 流片

工厂能读的“超精确打印文件”，送去制造。

GDSII
S5 · FPGA

先上真板子。

全综合、BRAM、时序约束、板级 bring-up；连续稳定跑目标负载 ≥1 小时。

S6 · ASIC

再谈流片。

SRAM、DFT、STA、PnR、DRC/LVS、pad/package；签核报告逐项有证据。

WHY 55NM?

不是越先进越好。

对 6502/NES 这样的芯片，55nm 已经足够；先做对，再做大。

小问题：为什么“能综合”不等于“能上板”？因为真板子还要过时序、BRAM、引脚和稳定性。
这一页讲香山模式的外环：内环保证正确，外环才把设计推到 FPGA 和流片。综合是把 RTL 翻译成门电路，布局布线是安排位置和连线，FPGA 要真上板，ASIC 要过签核。强调“能综合”不等于“能上板”，55nm 是项目目标。
15 · 制造16 / 19
THE XIANGSHAN WAY · 外环终点

在工厂里，用光“画”出芯片

设计过了七道门，才会来到工厂。光刻像一台超级投影仪：光穿过光罩，把图案缩得很小很小，印在涂了光刻胶的晶圆上。一层一层，重复几十次。

01

涂胶

在晶圆表面涂上一层对光敏感的光刻胶。

02

曝光

光穿过光罩，把电路图案投影到晶圆上。

03

显影 / 刻蚀

洗掉被光照过（或没照过）的部分，留下图案。

04

重复几十层

再涂胶、再曝光、再刻蚀，把三维结构叠出来。

无尘室一粒灰尘就可能毁掉一颗芯片
几百道工序光刻、刻蚀、沉积、清洗……
2–3 个月一颗芯片可能要走很久
一层一层不是打印一次，而是叠出来的
小问题：为什么芯片工厂要建得那么贵？因为要控制灰尘、温度、震动和化学品的纯度。
光刻可以比作“用光画画”：光穿过光罩，把图案缩小印到晶圆上。芯片不是一次打印出来的，而是几十层图案一层层叠出来的。这是香山模式外环的最后一站：设计、验证、签核都过了，才轮到工厂。可以让孩子想想：为什么工厂里要穿成“太空人”一样？

QUICK QUIZ

小测验：你记住多少？

先自己选，再点“揭晓答案”。答错也没关系，重要的是说出“为什么”。

1. 香山是什么？
A. 一座山B. 一颗开源 RISC-V 处理器C. 一种游戏机

答案：B。香山是一颗开源 RISC-V 处理器，不是旅游景点。

2. 香山模式里，哪个环最快？
A. 内环（分钟）B. 中环（每次提交）C. 外环（每次迭代）

答案：A。内环按分钟反馈，改一行 RTL 就能很快看到 PASS 或第一个差异。

3. 锁步 DiffTest 在做什么？
A. 让芯片更好看B. 让参考模型和 RTL 每一步对答案C. 直接流片

答案：B。同一镜像，两条队伍同时走；每一步对答案，第一个差异立刻停。

4. 七道门为什么要一道一道过？
A. 因为不能跳步，要有证据B. 因为门很漂亮C. 因为可以少写代码

答案：A。上一道没过，不许进下一道；每道门都要有命令、产物和已知限制。

5. 形式化验证和“抽考”最大的区别是什么？
A. 形式化验证更好看B. 对所有输入做证明，而不是只检查跑过的题C. 形式化验证不需要写代码

答案：B。仿真和 DiffTest 像抽考，只能覆盖跑过的程序；形式化验证用数学证明覆盖所有情况，但只覆盖建模到的那部分。

加分题：香山八件套里，你能说出哪四件？——参考模型、锁步 DiffTest、CI/检查点、生成化/开源协作。
老师提示：可以先让孩子举手选，再点开答案。重点不是答对，而是解释“为什么”。
答案：1-B 香山是一颗开源 RISC-V 处理器；2-A 内环最快，按分钟反馈；3-B 锁步 DiffTest 让参考模型和 RTL 每一步对答案；4-A 不能跳步，每道门都要有证据；5-B 形式化验证对所有输入做证明，抽考只覆盖跑过的题。加分题：参考模型、锁步 DiffTest、CI/检查点、生成化/开源协作。

QUIZ BANK

课后小测验

点开每一题看答案。可以打印出来，也可以课堂上口头抢答。

香山是什么？

一颗开源 RISC-V 处理器，不是一座山。它的前身是果壳（NutShell）。

香山模式的三个环分别是什么？

内环（分钟）、中环（每次提交）、外环（每次迭代）。

锁步 DiffTest 在做什么？

让参考模型和 RTL 用同一镜像同步走，每一步对答案；第一个差异立刻停。

七道门里 S3 是什么？

锁步 DiffTest。S0 契约冻结、S1 参考模型、S2 单元/总线、S3 DiffTest、S4 CI/检查点、S5 FPGA、S6 ASIC/PDK。

香山用什么生成 Verilog？

Chisel / FIRRTL。Open6502 目前手写 SystemVerilog，工具不同，门禁相同。

芯片里最小的开关叫什么？

晶体管。它可以“开”或“关”，分别表示 1 和 0。

从沙子到晶圆，中间要经过哪些步骤？

提纯硅 → 拉成硅锭 → 切片 → 晶圆。之后还要在晶圆上做几十层电路。

RTL 和软件程序最大的不同是什么？

软件通常一步一步执行；RTL 描述的是电路，很多部分可以在同一个时钟节拍同时工作。

为什么流片之前要做仿真和验证？

因为流片很贵，而且做错了很难改。仿真和验证能尽早发现 bug，降低风险。

Open6502 现在是一颗完成的芯片吗？

不是。它有可玩的模拟器、RTL 和测试，但 FPGA 原型和 55nm 流片还没完成。

一个 8 位 CPU 一次能表示多少个数？

0–255，一共 256 个数。8 个二进制位，每个位有 0 或 1 两种状态。

MINI GLOSSARY

小词典：十二个词就够了

如果孩子只记住这些词，这堂课就没白上。

晶体管
芯片里最小的“电控开关”，开=1，关=0。
晶圆
用来做芯片的圆形硅片，像一张大披萨。
RTL
用硬件语言写成的电路设计，描述“电路怎么连”。
仿真
在电脑里先让设计跑起来，不用真的做芯片。
验证
用测试和参考模型检查设计有没有做错。
流片
把设计送去工厂制造，英文叫 tapeout。
光刻
用光把电路图案印到晶圆上，像超级投影仪。
SoC
System on Chip，把 CPU、内存、图形等装进一颗芯片。
香山
一颗开源 RISC-V 处理器；用三个环和门禁做开发。
三个环
内环、中环、外环，分别按分钟、提交、迭代反馈。
七道门
S0–S6，每一步都要有命令、产物和已知限制。
Chisel
香山用来生成 Verilog 的硬件构造语言。
