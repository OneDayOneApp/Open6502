01 · 先找一找02 / 16
EVERYWHERE

芯片，藏在哪里？

如果没有芯片，世界会怎样？先别急着回答。找一找：你身边哪些东西会“思考”、会“控制”、会“记住”？

手机

拍照、上网、导航

手表

看时间、测心跳

汽车

控制发动机、刹车

冰箱

调温度、省电

游戏机

画面、声音、手柄

电饭煲

控制火候

芯片不神秘：它只是把“开关”做得非常非常小。小到一根头发丝里，能放下成千上万个开关。
小问题：如果把这些东西里的芯片都拿走，哪一个会最先“罢工”？
让孩子先列举，不要急着纠正。手机、手表、汽车、冰箱、游戏机、电饭煲只是引子。重点是把“芯片”从神秘的黑盒子，拉回到日常物品里。
02 · 芯片是什么03 / 16
A CITY ON A FINGERNAIL

一座“指甲盖上的城市”

把芯片放大，你会看到一座规划得整整齐齐的城市：有指挥中心、仓库、画家、音乐家，还有无数条道路。

01

晶体管 = 小开关

现代芯片里有几十亿个开关；每个只有“开”和“关”两种状态。开就是 1，关就是 0。

02

导线 = 道路

把 0 和 1 的信号，送到需要它的地方。路修得越好，信号跑得越快。

03

模块 = 街区

CPU、内存、图形、声音，各有各的工作，又通过总线互相说话。

开 = 1，关 = 0：1010两个数字，就能写出游戏、音乐和整座城市。
芯片不是“画”出来的，而是用一层层材料“做”出来的。下一站：从沙子开始。
晶体管不用讲得太深，先把它当成“电控小开关”。可以让孩子用手指比划：开是 1，关是 0。很多开关排在一起，就能表示数字、文字、图片和声音。补充一个对比：现代处理器有几十亿个晶体管，而 6502 只有几千个，但已经足够跑游戏。
03 · 从沙到硅04 / 16
FROM SAND TO SILICON

从一粒沙，到一片“硅圆饼”

芯片的“地基”是硅。硅藏在沙子里，但要先提纯、拉成硅锭、切成薄片，才能变成晶圆。

01

沙子

主要成分是二氧化硅

02

提纯硅

纯度做到 99.9999999%

03

硅锭

拉成一根圆柱

04

切片

切成薄薄的圆片

05

晶圆

像一张大披萨

硅是地壳里第二多的元素。沙子、石头里都有它，但要做芯片，必须提纯到非常非常干净。

一片晶圆，能切出几百到几千颗芯片。每颗芯片只占晶圆上一个小小的方格。

为什么要在无尘室？一粒灰尘落在晶圆上，就可能毁掉一颗芯片。

小问题：如果一颗灰尘就能毁掉芯片，工程师进车间前要穿什么？
沙子的主要成分是二氧化硅，硅是地壳中第二多的元素。电子级硅的纯度可以做到 99.9999999%（9 个 9）。晶圆像一张大披萨，每一小块就是一颗芯片。可以让孩子猜猜：为什么要穿无尘服？
04 · 芯片里的乐队05 / 16
INSIDE THE SOC

一颗芯片里，住着一支“乐队”

每个模块都有自己的工作。它们通过“总线”交换消息，就像乐队看着同一个节拍。

8 位是什么意思？CPU 一次处理 8 个二进制位，能表示 0–255。别小看它，1980 年代的游戏机就是用它跑出整个童年。
小问题：如果 CPU 是指挥，PPU 是画家，那“总线”更像什么？
可以把 SoC 想成一支乐队：CPU 是指挥，PPU 是画家，APU 是音乐家，RAM 是仓库，卡带是故事书，手柄是感官。总线就是大家共用的排练厅和节拍。8 位 CPU 一次处理 0–255，这个数字可以让孩子记住。
05 · 研发流程06 / 16
THE SIX STEPS

做一颗芯片，像盖一座城市

先想清楚要盖什么，再画图纸、写说明书、做模型、反复检查，最后才交给工厂。芯片研发，也是这六步。

01

想法

它要解决什么问题？给谁用？先有一个好问题。

02

规格

要会什么、不能做什么、花多少成本，都写清楚。

03

写 RTL

用硬件语言描述电路：谁和谁连、什么时候动。

04

仿真

先在电脑里“虚拟制造”，跑几百万次也不花钱。

05

验证

和参考模型逐项对比，像侦探一样找不同。

06

制造

综合、布局布线、流片、封装、测试，才真正变成芯片。

设计只是上半场。验证和制造，才是下半场。一颗芯片从想法到量产，常常要走 2–5 年。
小问题：如果只能保留一步，你会保留“写 RTL”还是“验证”？为什么？
六步不用让孩子全记住，先建立“先设计、再验证、最后制造”的顺序感。可以用盖房子打比方：想法是“要盖什么”，规格是图纸，RTL 是施工说明，仿真是模型，验证是验收，制造是真正开工。
06 · 想法与规格07 / 16
IDEA → SPEC

第一步：先想清楚“它要会什么？”

芯片不是“什么都想要”。规格书就是一张“愿望清单 + 边界”：既要写清楚能做什么，也要写清楚不做什么。

THE IDEA

做一颗能玩 NES 游戏的芯片，让童年跑进一颗芯片。

这句话听起来很简单，但它会决定后面每一个选择：要多快？要多小？要花多少钱？

指令集
6502，8 位
画面
256 × 240，图块 + 精灵
声音
5 个声音通道
输入
2 个手柄
工艺目标
55nm（长期目标）
面积 / 成本
越小越好，越省越好

注：55nm 是 Open6502 的长期流片目标，不是当前已经完成的工艺。

做芯片不能“全都要”。想要更快，可能要更大；想要更省电，可能要慢一点。工程师的工作，就是在限制里做选择。
小问题：如果让你设计一颗“校园芯片”，它最必须会哪三件事？
这一页可以让孩子先写“愿望清单”，再删到只剩三条。规格书不是越厚越好，而是越清楚越好。顺便强调：55nm 是长期目标，不是已经完成的芯片。
07 · 写 RTL08 / 16
WRITE THE HARDWARE

第三步：用“硬件语言”写下电路

软件像写步骤，硬件像画电路。Verilog / SystemVerilog 就是芯片工程师的“画笔”。

// 每个时钟上升沿，如果写使能为 1
always @(posedge clk) begin
  if (we)
    mem[addr] <= din;
end
01

不是“指令表”，是“电路说明书”。它描述的是电线怎么连、寄存器什么时候更新。

02

软件一步一步，硬件同时工作。很多电路会在同一个时钟节拍一起动。

03

写错一行，可能整颗芯片都受影响。所以后面才需要仿真和验证。

时钟就像节拍器。“时钟上升沿”就是大家一起迈出下一步的那一刻。芯片里的很多动作，都跟着这个节拍走。
小问题：如果软件是“按顺序做”，硬件为什么可以“同时做”？
不需要让孩子学会 Verilog，只要知道它和 Scratch 不一样：Scratch 是一步一步执行，硬件语言是在描述“电路长什么样、什么时候一起动”。时钟就是节拍器，上升沿就是大家一起迈步的那一刻。
08 · 仿真09 / 16
SIMULATE FIRST

第四步：先在电脑里“虚拟制造”

在真正流片之前，工程师会先让设计在电脑里跑起来。改一行代码、再跑一遍，比重新做一颗芯片便宜太多了。

01

测试激励

给芯片输入一组“题目”：复位、读内存、按手柄。

02

DUT · 被测设计

把 RTL 放进仿真器，让它按节拍一步一步跑。

03

结果与波形

看输出对不对，再看每一根信号什么时候变。

像飞机模拟器

先在地面练熟，再真正起飞。

不用真的做出一颗芯片，就能试几百万次。发现 bug 时，改代码、重跑，成本很低。

但是……

仿真通过 ≠ 芯片一定正确。

测试写漏了，bug 就可能溜过去。所以还需要下一关：验证。

仿真不是“跑一次看看”。工程师会写很多测试，覆盖正常情况、边界情况和“故意捣乱”的情况。
小问题：为什么不在电脑里多跑几次，而是要做真芯片？因为真芯片还要考虑速度、功耗、发热和制造。
仿真就像飞机模拟器：先在地面练熟，不用真的起飞。给芯片输入测试激励，让 RTL 跑起来，再看输出和波形。强调“仿真通过不等于一定正确”，为下一页验证做铺垫。
09 · 验证10 / 16
VERIFY LIKE A DETECTIVE

第五步：像侦探一样“找不同”

一个人写答案，另一个人检查。Open6502 用两个“选手”跑同一款游戏：软件参考模型 NEMU，和硬件设计 RTL。

RTL · 硬件设计

再用 SystemVerilog 写一遍

它描述真正要变成芯片的电路。每一帧画面、每一个状态，都要和参考模型对上。

10 · 走向工厂11 / 16
SYNTHESIS → TAPEOUT

第六步：把代码变成“真正的图纸”

RTL 是“做什么”，综合是“用哪些门实现”，布局布线是“零件放在哪、线怎么走”，最后变成工厂能读的 GDS。

01

RTL

人写的电路说明书：功能、时序、接口。

.sv / .v
02

综合

翻译成门电路：与门、或门、触发器。

netlist
03

布局布线

给几百万个零件安排座位，再把线连好。

layout
04

GDS / 流片

工厂能读的“超精确打印文件”，送去制造。

GDSII
WHY 55NM?

不是越先进越好。

对 6502/NES 这样的芯片，55nm 已经足够，而且更便宜、更容易验证。先做对，再做大。

TAPEOUT

流片 = 把设计送去工厂。

一次流片很贵，所以能先在电脑里验证的，绝不留到工厂。

CHECK

流片前还要过很多关。

时序、功耗、DRC、LVS、DFT……每一关都在问：真的准备好了吗？

小问题：为什么“布局布线”不能随便把零件放在一起？因为线太长，信号就会变慢。
这一页讲“从代码到工厂”的翻译过程。综合是把 RTL 翻译成门电路，布局布线是安排位置和连线，GDS 是工厂能读的版图文件。强调 55nm 是项目目标，不是“越先进越好”。
11 · 制造12 / 16
LIGHT DRAWS THE CHIP

在工厂里，用光“画”出芯片

光刻像一台超级投影仪：光穿过光罩，把图案缩得很小很小，印在涂了光刻胶的晶圆上。一层一层，重复几十次。

01

涂胶

在晶圆表面涂上一层对光敏感的光刻胶。

02

曝光

光穿过光罩，把电路图案投影到晶圆上。

03

显影 / 刻蚀

洗掉被光照过（或没照过）的部分，留下图案。

04

重复几十层

再涂胶、再曝光、再刻蚀，把三维结构叠出来。

无尘室一粒灰尘就可能毁掉一颗芯片
几百道工序光刻、刻蚀、沉积、清洗……
2–3 个月一颗芯片可能要走很久
一层一层不是打印一次，而是叠出来的
小问题：为什么芯片工厂要建得那么贵？因为要控制灰尘、温度、震动和化学品的纯度。
光刻可以比作“用光画画”：光穿过光罩，把图案缩小印到晶圆上。芯片不是一次打印出来的，而是几十层图案一层层叠出来的。可以让孩子想想：为什么工厂里要穿成“太空人”一样？
12 · 真实案例13 / 16
A REAL OPEN-SOURCE CHIP

我们正在做一颗真的芯片：Open6502

它不是玩具，也不是已经完成的成品。它是一颗正在生长的开源 6502/NES SoC：有 CPU、PPU、APU、总线和验证。

OPEN SILICON

一颗小芯片，五脏俱全。

从能玩的 NEMU 模拟器，到 SystemVerilog RTL，再到长期 55nm 流片目标。设计、代码、测试都公开，任何人都能检查、学习、帮忙。

诚实是工程的一部分。它还不是一颗成品芯片。我们把“还没做到”也写进官网，因为知道边界，才知道下一步往哪走。
数据来自 Open6502 README / STATUS，最后验证 2026-11-11。进度百分比是工程进度，不是流片完成度。
这一页把前面讲的东西落到真实项目上。Open6502 有 NEMU 参考模型、RTL、测试和 55nm 目标，但它还不是成品。可以特别指出“诚实”：把没做到的部分也写出来，是工程师很重要的品质。
13 · 你能做什么14 / 16
START SMALL, START NOW

想成为芯片工程师？从今天开始

不需要现在就学 Verilog。先把数学、科学、英语和好奇心练好，再从小项目开始。

01

玩二进制

用 0 和 1 写出自己的名字，看看电脑怎么“读”它。

02

学 Scratch / Python

先让电脑听你的话，再理解“程序”是什么。

03

拆旧电器

在大人陪同下看看里面有什么。别通电，先观察。

04

玩逻辑门

Minecraft 红石、逻辑积木，都能搭出“与、或、非”。

05

试试 Arduino / FPGA

让一盏灯亮起来，就是最小型的“硬件项目”。

06

画芯片城市

设计自己的 SoC：CPU 在哪？内存在哪？总线怎么走？

好奇心耐心合作诚实
最重要的一步：遇到不懂的，先问“为什么”，再动手试。芯片就是这样一层一层被想清楚的。
小问题：上面六件事里，你最想先试哪一件？为什么？
不要让孩子觉得“芯片工程师”遥不可及。二进制、Scratch、拆旧电器、红石、Arduino、画芯片城市，都是入口。最后落到四种超能力：好奇心、耐心、合作、诚实。
14 · 课堂互动15 / 16
QUICK QUIZ

小测验：你记住多少？

先自己选，再点“揭晓答案”。答错也没关系，重要的是说出“为什么”。

1. 芯片里最小的“开关”叫什么？
A. 晶体管B. 电容C. 电线

答案：A。晶体管像一个小开关，开是 1，关是 0。

2. 把设计送去工厂生产，叫什么？
A. 打包B. 流片C. 打印

答案：B。流片（tapeout）就是把设计交给工厂制造。

3. 为什么验证这么重要？
A. 因为流片很贵B. 因为好看C. 因为可以少写代码

答案：A。流片一次很贵，发现问题越早，代价越小。

4. 一个开关能表示几种状态？
A. 1 种B. 2 种C. 10 种

答案：B。开和关，也就是 1 和 0。很多开关组合起来，就能表示更多信息。

加分题：如果一颗芯片有 1 亿个晶体管，每个晶体管都能“开”或“关”，那它能表示多少种组合？——这个问题没有简单答案，但足够让工程师忙上很多年。
老师提示：可以先让孩子举手选，再点开答案。重点不是答对，而是解释“为什么”。
答案：1-A 晶体管；2-B 流片；3-A 因为流片很贵；4-B 两种，开和关。加分题没有要求算出具体数字，重点是让孩子感受“组合爆炸”。

QUIZ BANK

课后小测验

点开每一题看答案。可以打印出来，也可以课堂上口头抢答。

芯片里最小的开关叫什么？

晶体管。它可以“开”或“关”，分别表示 1 和 0。

从沙子到晶圆，中间要经过哪些步骤？

提纯硅 → 拉成硅锭 → 切片 → 晶圆。之后还要在晶圆上做几十层电路。

RTL 和软件程序最大的不同是什么？

软件通常一步一步执行；RTL 描述的是电路，很多部分可以在同一个时钟节拍同时工作。

为什么流片之前要做仿真和验证？

因为流片很贵，而且做错了很难改。仿真和验证能尽早发现 bug，降低风险。

Open6502 现在是一颗完成的芯片吗？

不是。它有可玩的模拟器、RTL 和测试，但 FPGA 原型和 55nm 流片还没完成。

一个 8 位 CPU 一次能表示多少个数？

0–255，一共 256 个数。8 个二进制位，每个位有 0 或 1 两种状态。

MINI GLOSSARY

小词典：八个词就够了

如果孩子只记住八个词，这堂课就没白上。

晶体管
芯片里最小的“电控开关”，开=1，关=0。
晶圆
用来做芯片的圆形硅片，像一张大披萨。
RTL
用硬件语言写成的电路设计，描述“电路怎么连”。
仿真
在电脑里先让设计跑起来，不用真的做芯片。
验证
用测试和参考模型检查设计有没有做错。
流片
把设计送去工厂制造，英文叫 tapeout。
光刻
用光把电路图案印到晶圆上，像超级投影仪。
SoC
System on Chip，把 CPU、内存、图形等装进一颗芯片。
