# Test ROMs

The `.nes` files in this directory are the MIT-licensed homebrew games from
the repository's top-level `roms/` directory. They are copied here so the web
player can be served as a self-contained static site.

| `hanoi.nes` | https://github.com/jdonald/nes-hanoi-tower | MIT | 0 (NROM) |
