Reusable playbooks for this repository. Each folder has a `SKILL.md` and can be installed with its `install.sh`.

|---|---|
| [xiangshan-chip-flow](xiangshan-chip-flow/) | Designing, verifying or reviewing a digital SoC/ASIC with the XiangShan-style loop: reference model → lockstep DiffTest → CI gates → checkpoint/replay → FPGA/PDK backend. |
