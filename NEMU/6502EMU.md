# 6502EMU：基于 NEMU 的 MOS 6502/NES 模拟器

6502EMU 在 [NEMU](https://github.com/NJU-ProjectN/nemu) 的框架上扩展了：

- MOS 6502/65C02 CPU
- 64 KiB 原始二进制运行模式、NEMU SDB 监视器
- Microsoft BASIC 1.1
- NES/Famicom 前端：2C02 PPU、2A03 APU、手柄、iNES/mapper、SDL2 视频音频

完整 NES 芯片级 golden reference 的设计、测试与验收清单见
[docs/nes-golden-reference/README.md](../docs/nes-golden-reference/README.md)。

## 构建

需要 C 编译器、GNU make、readline 和 SDL2（NES 前端）。可选安装 cc65 以编译
示例和 NES demo。

```sh
cd Open6502/NEMU
make m6502_defconfig
make -j8
```

生成 `build/6502EMU`。

## 原始 6502 程序

```sh
./build/6502EMU -b --log=/tmp/6502emu.log my_program.bin
```

默认加载到 `$8000` 并从加载地址开始执行。常用选项：

| 选项 | 含义 |
| --- | --- |
| `-b`, `--batch` | 批处理运行 |
| `-a`, `--load-addr=ADDR` | 镜像加载地址 |
| `-e`, `--pc=ADDR` | 入口 PC |
| `-r`, `--reset` | 从 `$FFFC` 复位向量启动 |
| `-n`, `--max-inst=N` | 指令数上限 |
| `-s`, `--stop-pc=ADDR` | 到指定 PC 停止 |
| `-C`, `--65c02` | 启用 65C02 扩展 |
| `--cpu=65c02` | 同上 |
| `-l`, `--log=FILE` | 日志/trace 文件 |
| `--hash` | NES 模式输出确定性 frame/audio hash |
| `--save-state=FILE` | NES 运行结束后保存状态快照 |
| `--load-state=FILE` | NES 启动时恢复状态快照 |
| `--record-input=FILE` | 按帧记录 1P/2P 手柄输入 |
| `--replay-input=FILE` | 按帧回放手柄输入 |

主机 I/O：

- `$F001` 写：输出字符
- `$F002` 写：退出，值作为退出码
- `$F003` 读：控制台输入，EOF 时结束模拟

## 65C02

新增 `STZ`、`BRA`、`PHX/PHY/PLX/PLY`、`TSB/TRB`、`BIT #`、
`INC A/DEC A`、`JMP (abs,X)`、`(zp)`、`RMB/SMB`、`BBR/BBS`、`WAI/STP`
等扩展；6502 模式保留常见非法 NOP 的兼容行为。

示例：

```sh
./build/6502EMU -b --65c02 test.bin
```

## Microsoft BASIC

```sh
./basic/run.sh
```

启动时输入：

```text
MEMORY SIZE? 32768
TERMINAL WIDTH? 80
WANT SIN-COS-TAN-ATN? N
```

然后输入 BASIC 程序，`RUN` 执行；Ctrl-D 退出。另见
[basic/README.md](basic/README.md)。

## NES/Famicom

```sh
./nesgame/build.sh
./nesgame/run.sh
# 或
./build/6502EMU --scale=3 nesgame/game.nes
```

键盘：

| 键盘 | 手柄 |
| --- | --- |
| W/A/S/D | 1P 十字键 |
| Space / Z / X | 1P A / A / B（Space 和 Z 都是 A） |
| C/V | 1P Select/Start |
| 方向键 | 2P 十字键 |
| `,` / `.` | 2P A/B |
| `/` / `'` | 2P Select/Start |
| Esc | 退出 |

无窗口运行：

```sh
./build/6502EMU --headless --no-audio --frames=180 \
  --screenshot=/tmp/nes.ppm --wav=/tmp/nes.wav \
  nesgame/game.nes
```

当前 NES 支持：

- iNES；mapper 0/1/2/3/4/7
- 2C02 PPU：背景、精灵、NMI、OAM DMA、调色板、scanline 级渲染
- 2A03 APU：脉冲 x2、三角、噪声、包络/长度，DMC 未实现
- 标准手柄 1/2
- `--screenshot`、`--wav`、`--hold`

这不是逐点精确的 NES 硬件模型；芯片级范围与验收标准见
[docs/nes-golden-reference](../docs/nes-golden-reference/README.md)。

## 测试


NES PPU/输入/APU、状态快照，以及 Klaus 6502 功能测试。

## 代码结构

```text
src/isa/m6502/     6502/65C02
src/nes/           NES 总线、PPU、APU、mapper、SDL2 前端
basic/             Microsoft BASIC 1.1
nesgame/           自带 NROM 演示游戏
tests/             回归测试
docs/nes-golden-reference/  完整 golden reference 设计/测试/清单
```

## 限制

- PPU 为 scanline 级，不是逐 dot；MMC3 IRQ 为近似
- APU DMC、扩展音频未实现
- mapper 仅 0/1/2/3/4/7
- 不是完整芯片 golden reference；当前是功能型原型/验证载体
