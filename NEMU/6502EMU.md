# 6502EMU: A NEMU-based MOS 6502/NES Emulator

6502EMU extends the [NEMU](https://github.com/NJU-ProjectN/nemu) framework with:

- MOS 6502 and 65C02 CPU support
- 64 KiB raw-binary execution and a NEMU-style monitor
- Microsoft BASIC 1.1
- NES/Famicom frontend: 2C02 PPU, 2A03 APU, controllers, iNES mappers,
  SDL2 video/audio

For the full-chip reference plan see
[docs/nes-golden-reference/README.md](../docs/nes-golden-reference/README.md).
For the RTL chip design see
[docs/open6502-chip/architecture.md](../docs/open6502-chip/architecture.md).

## Build

Requirements: a C compiler, GNU make, readline and SDL2. cc65 is optional and
only needed to rebuild the BASIC image and demo game.

```sh
cd Open6502/NEMU
make m6502_defconfig
make -j8
```

The binary is `build/6502EMU`.

## Raw 6502 programs

```sh
./build/6502EMU -b --log=/tmp/6502emu.log my_program.bin
```

The default load address is `$8000`; execution starts at the load address.

| Option | Meaning |
| --- | --- |
| `-b`, `--batch` | batch mode |
| `-a`, `--load-addr=ADDR` | image load address |
| `-e`, `--pc=ADDR` | entry PC |
| `-r`, `--reset` | start from the `$FFFC` reset vector |
| `-n`, `--max-inst=N` | instruction limit |
| `-s`, `--stop-pc=ADDR` | stop at PC |
| `-C`, `--65c02` | enable 65C02 extensions |
| `--cpu=65c02` | same as above |
| `-l`, `--log=FILE` | log/trace file |
| `--hash` | NES mode: print deterministic frame/audio hash |
| `--save-state=FILE` | NES mode: save a state snapshot after the run |
| `--load-state=FILE` | NES mode: load a state snapshot before the run |
| `--record-input=FILE` | record per-frame 1P/2P controller state |
| `--replay-input=FILE` | replay per-frame controller state |

Host I/O:

- `$F001` write: output a character
- `$F002` write: exit with the written byte
- `$F003` read: console input; EOF stops the simulation

## 65C02

Available extensions include `STZ`, `BRA`, `PHX/PHY/PLX/PLY`, `TSB/TRB`,
`BIT #`, `INC A/DEC A`, `JMP (abs,X)`, `(zp)`, `RMB/SMB`, `BBR/BBS` and
`WAI/STP`.

```sh
./build/6502EMU -b --65c02 test.bin
```

## Monitor

```text
(6502EMU) help
(6502EMU) info r
(6502EMU) x 8000 32
(6502EMU) d 8000 8
(6502EMU) si 4
(6502EMU) c 1000
(6502EMU) q
```

## Microsoft BASIC

```sh
./basic/run.sh
```

At the boot prompts:

```text
MEMORY SIZE? 32768
TERMINAL WIDTH? 80
WANT SIN-COS-TAN-ATN? N
```

Enter BASIC lines in uppercase, then `RUN`. Press Ctrl-D to exit.

Non-interactive demo:

```sh
./basic/run-demo.sh
```

See [basic/README.md](basic/README.md).

## NES/Famicom

```sh
./nesgame/build.sh
./nesgame/run.sh
# or
./build/6502EMU --scale=3 nesgame/game.nes
```

Keyboard:

| Key | Controller |
| --- | --- |
| W/A/S/D | 1P D-pad |
| Space / Z | 1P A (jump) |
| X | 1P B |
| C/V | 1P Select/Start |
| Arrow keys | 2P D-pad |
| `,` / `.` | 2P A/B |
| `/` / `'` | 2P Select/Start |
| Esc | quit |

Headless run:

```sh
./build/6502EMU --headless --no-audio --frames=180 \
  --screenshot=/tmp/nes.ppm --wav=/tmp/nes.wav \
  --hash nesgame/game.nes
```

Current NES support:

- iNES; mappers 0/1/2/3/4/7
- 2C02 PPU: background, sprites, NMI, OAM DMA, palette, per-dot background
  pixels and sprite 0 check; sprite evaluation is still scanline-composed
- 2A03 APU: pulse x2, triangle, noise, envelopes/length, DMC core
- standard 1P/2P controllers
- state snapshots, input recording/replay
- `--screenshot`, `--wav`, `--hold`, `--hash`

This is not a cycle-exact NES hardware model yet. See the feature matrix for the
current limitations.

## Tests

```sh
./tests/run.sh
RUN_KLAUS=1 ./tests/run.sh
./tests/difftest/run.sh
```

Coverage includes the built-in image, hello, custom load address, BASIC, 65C02,
NES PPU/input/APU, REF/frontend hash parity, state snapshots, input replay,
PPU timing and the Klaus 6502 functional test.

## Layout

```text
src/isa/m6502/     6502/65C02
src/nes/           NES bus, PPU, APU, mappers, SDL2 frontend
src/nes/ref/       NEMU golden-reference core
basic/             Microsoft BASIC 1.1
nesgame/           bundled NROM demo game
tests/             regression tests
docs/              golden-reference and chip design documents
```

## Limitations

- PPU background pixels are generated in the dot loop, but fetch/shift and
  sprite evaluation are not yet cycle/dot exact.
- DMC has no CPU DMA stall yet.
- Mapper support is limited to 0/1/2/3/4/7.
- NES PPU/APU/mapper extended DiffTest is not complete.
- No hardware capture alignment yet.
- This is not a complete chip golden reference.
